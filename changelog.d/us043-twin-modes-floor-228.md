Changed (US-043): core now requires hq-cli 5.345.228 or newer (`requiresHqCli` in `core/core.yaml`, was 5.345.221). It is the first published hq-cli whose `hq core register-project` accepts `--board` and whose `hq core delegate send` accepts `--reconcile`, so the `/brainstorm`, `/prd` and `/delegate` skills now run those through `hq core` instead of `bash core/scripts/register-project.sh` and `bash core/scripts/hq-delegate-send.sh`. `core/scripts/ci/rewrite-core-callers.mjs` no longer holds those two helper modes. Its new `MODE_FLOORS` table gives each mode its first hq-cli, and `--check` fails with `file:line` when a caller runs a mode that needs more than `requiresHqCli`. Tests: `core/scripts/tests/rewrite-core-callers.test.mjs` (the two modes move, mode calls are found, `--check` fails below the mode floor and passes at it) and `core/scripts/tests/cli-hosted-pinned-cli.test.sh` (the floor value).
