Added (Google Antigravity host): Google Antigravity is now a supported HQ host. HQ ships `.agents/rules/hq.md`, an always-on Antigravity rule that points at the charter and names the two files the charter imports with `@` lines (`.claude/personal-context.md` and `personal/CLAUDE.md`), which Antigravity does not expand. Antigravity already reads `AGENTS.md` and the HQ skills under `.agents/skills`. The charter, README, user guide, directory map, product model and hook coverage doc list Antigravity, and the Work Mesh reporting policy says how to report by hand there. `hq-session.sh` prints the `--session-id` / `HQ_SESSION_ID` remedy inside an Antigravity shell, and `setup-status.sh` counts Antigravity conversation history as prior AI context. HQ hook guards do not run in Antigravity yet. Tests: `core/scripts/tests/antigravity-host-contract.test.sh`.
