The scope guard no longer refuses a bare skill name such as `code-review` or `init` when another company's skill shares it only as the part after the colon of a mirror folder (`otherco:code-review`) or as a source folder name. Claude Code does not load that folder under the bare name. A bare name that a company skill's frontmatter `name` carries, or that a folder in `companies/<slug>/.claude/skills` carries, is still refused, as is a company folder whose `SKILL.md` the guard cannot read.
