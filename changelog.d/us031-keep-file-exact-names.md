- `core/scripts/remove-installed-test-files.sh`, which `/update-hq` runs, now leaves alone folders whose names start with `#` or a space, end in a space, or contain a newline. The script used to give the checker its list of kept folders one name per line. The checker trims each line and skips lines that start with `#`, so test files inside those folders could be moved to the backup folder. The script now keeps that list NUL-separated and checks the checker's findings against it.
