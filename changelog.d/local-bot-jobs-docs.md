Docs: `agents-and-bots.md` and `outpost-jobs-spec.md` now describe local bot jobs as kept and fired on the bot's own computer, and document the built-in daily `hot-signal-sync` job (06:30 local time). With the signals engine flag off, the default, it runs `hq sources sync`, whose signals pass needs Claude Code signed in on the computer; with the flag on it runs `hq signals run`. The ontology worker README lists that local bot job as the default runtime, with an Outpost routine and a cloud agent as alternatives.
