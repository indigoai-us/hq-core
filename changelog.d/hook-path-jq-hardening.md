Fixed (hooks): the hook PATH recovery no longer puts a folder found only because it holds jq in front of the user's PATH. Such a folder is added only while jq is missing, and always at the end, so its other programs cannot shadow the user's. On Windows the winget folder check also survives a shell with `failglob` set, and the drive letter is written in lowercase, as Git Bash does, so the folder is not added twice.
