- Core skills, the Cowork MCP server and the sync docs now call the owning commands instead of the duplicates: `hq daemon sync status --local` for the local sync journal summary (was `hq sync status`), `hq daemon sync mode list` for the membership table (was `hq sync mode --show`) and `hq daemon sync mode set <company> <mode>` to change a company's footprint (was `hq sync mode <mode>`). The Cowork `hq_cli` tool no longer admits `sync status`; it points at `daemon sync status --local`. `auth status` and `packages update` are marked retiring in `core/functions.yaml` (use `hq whoami --check` or `hq whoami --json`, and `hq packs update --registry`); they still run. Core now requires hq-cli 5.345.221 or later, the first release with every owning command.
