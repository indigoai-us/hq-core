The hqd hook shim now makes one bounded attempt instead of two, so the daemon call takes at most its 3 s budget (plus 250 ms) instead of 6.15 s when the daemon is busy. Socket I/O is non-blocking, which fixes a hang where a daemon that stopped reading a payload over 8 KB held the hook past its timeout, and a hard timer ends a stalled client. master-hook passes the shim a deadline counted from its own start, and skips the hqd call for PreToolUse only when its parent process is the HQ Fleet local hook adapter (which has already run the same scope check) with the adapter's variables set and the scope authorizer not opted out; the variables alone no longer turn the call off. The adapters' fallback guard list, used when hook-registry.json is missing or malformed, now runs the scope authorizer for Edit, Write, MultiEdit and NotebookEdit.
