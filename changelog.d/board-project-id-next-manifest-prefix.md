Fixed (project ids): `core/scripts/board-project-id.sh next <company>` no longer exits 2 when the company's board has no `<prefix>-proj-<NNN>` ids yet, which is how `/brainstorm` and `/prd` call it for a company's first project. With no `--prefix` and no such ids (or no board file), it now uses the company's `prefix:` from `companies/manifest.yaml` and prints `<prefix>-proj-001`. `--prefix` and existing ids still take precedence. It still exits 2 when the manifest has no prefix for the company or the prefix is not lowercase letters and digits, and when the board is not valid JSON. Covered by `core/scripts/tests/board-project-id.test.sh`.
