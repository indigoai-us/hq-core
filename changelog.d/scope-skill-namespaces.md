The scope guard no longer refuses three more ordinary calls. A company's own skill (`<your-company>:name`) loads in a session bound to that company even when another company has a skill of the same name. A plugin or pack skill (`plugin:name`) is compared by its whole name, so another company's skill called `name` no longer refuses it. A `python3 -c "..."` or `node -e "..."` program that spans several lines is read as program text, so a call such as `k(v[k2],p+k2+'.')` in it is no longer taken for a zsh glob qualifier. A skill folder whose `SKILL.md` links into a company outside the session's scope is now refused whatever the folder is called.
