Fixed (scheduled-task company bind, feedback 3146ee8d, a856bc99): Scheduled tasks from the Claude desktop app now bind to their company. The app puts a fixed "This is an automated run of a scheduled task" paragraph, earlier runs' notes and an optional skill line ahead of the task text, and HQ read that wrapper as the task: a company named in the task's first line never counted, and a company path in an earlier run's notes could block the bind or bind the session to that company instead. HQ now reads only the task text (plus the run's folder and the task file path), so the first company write in an unattended run is no longer blocked waiting for a manual bind. Tests: case 12b in core/scripts/tests/prompt-company-first-message-bind.test.sh runs the prompt in the shape the Claude desktop scheduler builds it.
