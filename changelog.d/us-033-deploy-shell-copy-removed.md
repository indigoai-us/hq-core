Removed (deploy): `/deploy` now makes every hq-deploy API call through `hq deploy` and needs hq-cli 5.345.246 or newer; Phase C stops with an upgrade message on an older CLI (US-033, last part of c1). `deploy-api-request.sh`, `list-apps.sh` and `site-events.sh` are deleted with their tests. The app list comes from `hq deploy list --json`, which reads every page and stops the deploy on any failure. Site events use `hq deploy events enable|list|reply|watch`. Owner comments use `hq deploy comments list|reply|resolve`. `comments-watch.sh` keeps its arguments and output lines but polls through `hq deploy comments list --json` and no longer reads `HQ_DEPLOY_JWT`. `deploy-record-backfill.py` lists apps with one `hq deploy list` call and fails with `hq_cli_too_old` when the list lacks `ownerId` or `passwordProtected`. Tests: `deploy-skill-no-shell-api-copy.test.sh` (new), `deploy-comments-watch.test.sh`, `deploy-record-backfill.test.sh`, `deploy-skill-gate-before-upload.test.sh`.
