The Company Outpost sign-in watcher now tells the cloud when the box's Claude sign-in is lost or refused. On a change to a non-ok credential class it sends `credential-lost` with the class (missing, expired, bad_mode and the other classes it already logs), and it sends `credential-ok` once the credential is usable again. The cloud alerts the company owners once per incident and shows the jobs as blocked until someone signs in. A failed report is retried after a minute, or dropped when the server refuses it (for example an older server without the action).
