Added (skills) `/tui-monitor`, a skill for building live, read-only terminal monitors. It scaffolds a standard-library Python renderer and a collector that runs on each watched machine over ssh with nothing installed remotely, reads hosts from `~/.config/<name>/hosts`, and covers verdict rules, width-adaptive layout, `--once` and `--local`, `.command` launchers and a self-test (one frame at three widths, a pseudo-terminal run that quits on `q`, and no collector left running).
