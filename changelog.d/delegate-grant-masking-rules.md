Fixed (delegate): in transfer mode, `core/scripts/hq-delegate-grant.sh` now also grants the narrower ACL rules under the project that carry no grants. hq-pro's ACL tree lists those only in `masking`, not in `children`, yet each one still overrides the project grant for the keys it covers. Before this fix the recipient got no access there while the manifest said "granted". Exact-path and private-folder rules under the project are granted too, not only `/*` rules. A rule the recipient already holds at the same or a higher permission is left as it is. A truncated `masking` list stops the grant instead of leaving rules unchecked. Tests: `core/scripts/tests/hq-delegate-grant.test.sh` section 1b-4 covers grant-less masking rules (bare and private-folder), a masking rule outside the project, truncation, an already-held admin rule, and an exact-path rule.
