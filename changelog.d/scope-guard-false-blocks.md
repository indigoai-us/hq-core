The Bash guards no longer block three ordinary commands: a grep pattern with an escaped dollar sign (`"var \$="`), a program path with a space that is set in a variable and run as `"$C"`, and a quoted heredoc with an apostrophe in its text when the same command also runs a script. A variable whose value has a space is still refused as a command when it is used without double quotes, and text after an apostrophe in a heredoc is still checked.
