Added `core/functions.yaml`, a manifest that lists every hq command, daemon function, hook and core script with one owner, the hosts it runs on, how often it runs and its state (live, trial, retiring or removed). The retired-hook cleanup now reads its list of retired files from the manifest. It removes the files it removed before and one more, `core/scripts/benchmark-turn-timing.sh`, when the copy on the install matches the released one; an edited copy is kept and named. The CLI-hosted manifest no longer has retired and deleted states: a removed script is an entry in the function manifest.
