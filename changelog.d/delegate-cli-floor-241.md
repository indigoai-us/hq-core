Changed (delegate): `/delegate` now requires hq-cli 5.345.241 or newer and stops with an upgrade message on older installs. 5.345.241 is the first release whose native secrets step matches `core/scripts/hq-delegate-secrets.sh` (hq-cli #3344 and #3350; 5.345.239 and 5.345.240 were never published). It checks that every secret name exists before sharing any, reads the project `.env.schema` and then `prd.json` `metadata.secrets` before falling back to the repo-wide schema, stops on a missing or unreadable schema, and shares agent and person-uid recipients through the grant step's `grantPrincipal`. Earlier native releases could share every name in the repo schema, or leave a partial grant after a missing name. The core-wide floor in `core/core.yaml` is unchanged. Tests: `core/scripts/tests/hq-delegate-skill.test.sh` requires the 5.345.241 skill check and upgrade message.
