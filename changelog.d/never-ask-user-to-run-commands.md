Added the `hq-never-ask-user-to-run-commands` policy. HQ assistants now run commands themselves and no longer tell a person to open a terminal or type a slash command. When a step belongs to the person, such as approving a sign-in or typing a secret value, the assistant opens the page or gives a link and waits. The policy allows a command only when the person asks for one, or when a deliberate safety block leaves no other route (creating a personal-vault secret link from a company-locked session).
