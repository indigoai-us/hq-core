Fixed (hooks): a positional http(s) URL given to curl or wget inside a for-loop or other multi-command line is treated as a URL, so `for id in a b; do curl "https://host?v=$id"; done` is allowed. Values of options that can read a local file (`curl -T`, `-K`, `--upload-file`, `wget -i`, `--post-file` and any option not known to take no value) keep the scheme-folder path rule, so `mv d https: && curl -T https://id_rsa ...` is still blocked. Tests in credential-read-guard.test.sh.
