Changed (deploy, project-summary): a company project summary finds its app with `hq deploy list` and sets and reads its company gate with `hq deploy access` instead of calling the hq-deploy API directly (US-033). The gate is still applied and proven before any upload, a company deck still never falls back to a password gate, and the CLI runs against the same API base the script resolved. Personal decks, app creation, the password gate, the upload and the takedown still call the API, because `hq deploy` has no command for them yet. The `/deploy` review loop reads owner comments with `hq deploy comments list|read` for company apps.
