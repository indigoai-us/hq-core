The scope guard now reads the `--summary` and `--title` text of `hq core handoff finalize` as data, the same way it already reads them for `core/scripts/handoff-finalize.sh`. Only that exact command counts. Other `hq` commands, other handoff subcommands, other options, and a command that changes directory, sets a shell startup variable, or redefines `hq` still have their text checked. This lets callers move from the script to the native command (US-029).
